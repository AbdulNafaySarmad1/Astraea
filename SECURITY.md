# Security policy

Astraea is an early-stage project and is **not production-ready** (see the README). We still take security reports seriously, because the design goals depend on them.

## Reporting a vulnerability

**Please do not open a public issue or pull request for a security problem.**

Report it privately with GitHub's private vulnerability reporting:

1. Go to the [Security tab](https://github.com/AbdulNafaySarmad1/Astraea/security) of this repository.
2. Choose **Report a vulnerability**.
3. Describe what you found, how to reproduce it, and the impact you expect.

Helpful details: affected commit or version, configuration, proof of concept, and any suggested fix.

## What to expect

- We will acknowledge your report as soon as practical and keep you updated on progress.
- We will credit you in the fix, if you want that.
- Please give us reasonable time to fix the problem before you disclose it publicly.

## Scope

In scope: the code, contracts, and deployment files in this repository.

Out of scope: third-party dependencies (report those upstream, though tell us if we should upgrade), and development fixtures or demo credentials that are clearly labelled as such.

## Supported versions

There are no production releases yet. Security fixes land on the default branch.
