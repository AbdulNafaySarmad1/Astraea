# Code of Conduct

We want this project to be a place where people can do good technical work with respect for each other.

## Our standard

Expected:

- Be respectful and assume good faith.
- Give and receive feedback about the work, not the person.
- Be patient with newcomers and with people working in a second language.
- Credit other people's work.

Not acceptable:

- Harassment, insults, discrimination, or personal attacks.
- Sexualized language or unwelcome attention.
- Publishing someone's private information.
- Spam, trolling, or deliberately derailing discussions.

## Scope

This applies in this repository's issues, pull requests, discussions, and any space where someone represents the project.

## Enforcement

Maintainers may edit or remove comments, close or lock threads, and block people from the repository when behavior breaks this code. To report a problem, contact the maintainer ([@AbdulNafaySarmad1](https://github.com/AbdulNafaySarmad1)) privately through GitHub. Reports are handled with discretion.

Security vulnerabilities are a different channel: see [SECURITY.md](SECURITY.md).
